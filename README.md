## Featured Hands-On Lab

### PostgreSQL / Tiger Data / TimescaleDB Readiness Lab

This lab documents my hands-on exploration of PostgreSQL and TimescaleDB concepts relevant to a Database Support Engineer role.

The environment was created for technical learning and product familiarization, not presented as production PostgreSQL experience.

Topics explored include:

- PostgreSQL SQL execution and query analysis
- `EXPLAIN` and `EXPLAIN ANALYZE`
- TimescaleDB hypertables
- Time-based chunk partitioning
- Additional hash dimensions
- Chunk inspection and chunk pruning
- Index behavior across chunks
- Tiger Data Hypercore
- Rowstore and columnstore behavior
- Columnar scans and vectorized aggregation
- Compression and storage statistics
- Automated compression policies
- `time_bucket`
- Continuous aggregates
- Continuous aggregate metadata
- Tiger Cloud console workflows

Example observations from the lab include:

- Verifying chunk exclusion through execution plans
- Comparing rowstore and columnstore access paths
- Observing mixed rowstore and compressed columnstore data within a logical chunk
- Measuring storage reduction after compression
- Creating daily time-series summaries using `time_bucket`
- Creating and inspecting a continuous aggregate and its internal materialization hypertable

This lab demonstrates how I apply my existing database-support experience to a new PostgreSQL-based platform through evidence-driven testing and execution-plan analysis.
